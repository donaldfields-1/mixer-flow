# Interactive Mixer Flow

A single-page, interactive flow chart for planning and executing mixer events.  
This site is **static** (no backend) and can be hosted with **GitHub Pages**.

## Files
- `index.html` — interactive flow chart (all-in-one, offline-friendly)
- `.nojekyll` — tells GitHub Pages to serve files without Jekyll processing

## Quick Publish (GitHub Pages)
1. Create a **public** repo on GitHub (e.g., `mixer-flow`).
2. Upload **both** files: `index.html` and `.nojekyll` (drag-and-drop on the repo page).
3. Go to **Settings → Pages**.
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` (or `master`), folder: `/ (root)`
   - Click **Save**.
4. Wait ~1–2 minutes, then visit:
   `https://<your-github-username>.github.io/mixer-flow/`

## Customize
Open `index.html` and edit titles, colors, or steps. Save and re-upload to update your live site.
